# Blog UI 轻量升级设计

日期：2026-04-17

## 目标

在不更换技术栈、不引入重型 UI 组件库的前提下，对当前博客做一轮轻量升级，使其更符合个人技术博客与求职展示场景。

## 设计原则

- 保持极简、轻量、静态部署友好
- 优先提升信息层次、可读性与个人定位表达
- 尽量复用现有 Next.js App Router 与 Tailwind 结构
- 不做与当前目标无关的重构

## 本次范围

1. 首页 Hero 升级，强化个人定位与技术方向展示
2. 文章列表卡片化，补充 `series` 与 `tags` 元信息
3. 优化摘要生成逻辑，避免直接截断 Markdown 原文
4. 升级文章详情页头部信息与正文排版样式
5. 优化全局导航与页脚文案，增强整体完成度

## 实现方案

### 首页

- 新增个人定位标题与副标题
- 展示学校、专业、毕业时间、求职方向
- 展示重点专题标签
- 文章区增加数量说明与更清晰的分组结构

### 数据层

- 在 `PostData` 中增加 `series`、`tags`
- 新增 Markdown 纯文本提取与摘要生成逻辑
- 将默认分类从 `Uncategorized` 调整为 `未分类`

### 文章页

- 强化标题区的返回入口、日期、分类、系列与标签展示
- 将正文放入独立白底容器
- 统一标题、引用、行内代码、代码块样式

### 全局样式

- 添加更柔和的背景层次
- 增加文本选中样式
- 优化技术文章的 prose 展示效果

## 验证方式

- 执行 `npm run build`
- 检查首页与文章页均可正常静态构建
- 确认未引入新的 TypeScript 或构建错误
